环境准备

 1. Python 环境确保已安装 Python 3.x。您可以通过命令 python --version 或 python3 --version 检查版本。
 2. 安装 Selenium 库在命令行中运行以下命令安装 Selenium：pip install selenium
 3. Chrome WebDriver
 • 下载与您 Chrome 浏览器版本匹配的 ChromeDriver。
 • 将 ChromeDriver 的可执行文件路径添加到系统环境变量，或者将其放置在脚本所在的目录中。




运行

1.将以上代码保存为一个 bing_search.py文件；
2.在命令行中切换到脚本所在目录，然后运行：
python bing_search.py
或 python3 bing_search.py
